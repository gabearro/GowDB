# Working in this repo

## Commits

Do not add `Co-Authored-By` trailers, "Generated with Claude Code" lines, or any
other tool attribution to commit messages or PR bodies. `includeCoAuthoredBy` is
false in `.claude/settings.json`; this file is the reason, so neither gets
"fixed" back to the default by someone who finds the setting without it.

Commits here are authored by `granular <dev@localhost>` and say what changed and
why. That is the whole of the convention.
